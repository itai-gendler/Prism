# Album

A catalog release with its track sequence and library bookmark.

## Information kept

- **Title** — Release name.
- **Artists** — Artists credited to the release.
- **Release** — Release type, year and explicit labeling when supplied.
- **Tracks** — Track sequence and popularity markers when supplied.
- **Artwork** — Release cover.
- **Saved** — The library bookmark status returned by YouTube Music.
- **Offline copy** — The last saved release details and tracks.
